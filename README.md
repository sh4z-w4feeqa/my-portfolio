# cosmic-themed-portfolio

**Interactive Portfolio:**

This is a personal portfolio website built using HTML, CSS and JavaScript. It showcases my skills, projects, certifications, and contact details with a cosmic background and shooting star animations.


**Features:**
* Starfield Zoom overlay intro
* Night sky backdrop as dark mode
* Evening sky backdrop with drifting clouds during light mode
* Light and Dark mode toggle
* Fully responsive (desktop, tablet, mobile)
* Modern UI with glowing effects and smooth animations
* Styled sections for Skills, Certificates, Projects, Internships and Education

**Technologies Used:**
* HTML5
* CSS3
* JavaScript
* AWS S3 and CloudFront

**Deployment:**
The portfolio is deployed using Amazon S3 and AWS CloudFront.

Deployment Steps (Summary):
1. Create an S3 bucket
2. Upload the necessary files (index.html, style.css and script.js)
3. Deploy to CloudFront. 
4. Configure bucket policy so that only CloudFront has access to the bucket. 
5. The website is securely hosted and accessible via a public CloudFront link.
